One-time setup

Paste an OpenAI API key so transcription runs in the cloud. It takes about 20 seconds for an hour of audio and costs about 36¢ per hour. The key is saved only on this phone.

  1. Open platform.openai.com/api-keys and tap Create new secret key
  2. Copy it and paste it here

No key? Open Settings and switch to on-device mode. That works offline but only for clips under about 15 minutes on a phone.

Transcription starts as soon as you pick a file. Hour-long files take about 20 seconds in cloud mode.
