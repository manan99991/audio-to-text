One-time setup (free)

Transcription runs on Groq's free Whisper service. Takes about 15 seconds for an hour of audio. No card needed. The key is saved only on this phone.

  1. Open console.groq.com/keys, sign in with Google, tap Create API Key
  2. Copy it and paste it here
